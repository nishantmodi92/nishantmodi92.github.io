Delta-based sync, deterministic merges, conflict resolution, snapshot restore, predictive caching, and retry queues. Achieved 70% fewer conflicts and 30% faster cold starts.

Architecture diagram (description)

Local cache (Room) → Delta computation → Pending queue → Server (Firestore) → Conflict resolver → Deterministic merge → Snapshot snapshot/restore. Retry & idempotency layers ensure safety under flaky networks.
